## Kinetic Model Description

This folder contains all scripts required for numerical simulations of the kinetic model.

### File Overview

1. **nodModel_ODE.m**  
   Defines the system of ordinary differential equations (ODEs) for the kinetic model. The ODEs are constructed using flux functions implemented in **nodModel_Flux.m**, including reactions generated by **rxns.m** based on the rules defined in **funs12.m**.

2. **Vmaxvalues.m** and **kineticparams.m**  
   Contain the representative \(V_{\max}\) values and kinetic parameters used in the model, respectively.

3. **nodModel_Run.m**  
   Main script for running simulations. This script solves the ODE system and computes nitrogen fixation rate and efficiency.

---

### Notes
- All scripts are written in MATLAB and are intended to be run together as part of the kinetic modeling workflow.  
- Refer to the main manuscript and supplementary materials for detailed model formulation and parameter definitions.


## Workflow Overview

The overall workflow of the kinetic model simulation is illustrated below:

### Step-by-step pipeline

1. **Reaction Definition**  
   - Reaction rules are defined in **funs12.m**  
   - Reaction networks are generated in **rxns.m**

2. **Flux Construction**  
   - Flux equations are assembled in **nodModel_Flux.m** based on the generated reactions

3. **ODE System Assembly**  
   - The system of ordinary differential equations (ODEs) is defined in **nodModel_ODE.m**, incorporating all flux terms

4. **Parameter Initialization**  
   - Kinetic parameters are loaded from **kineticparams.m**  
   - \(V_{\max}\) values are assigned from **Vmaxvalues.m**

5. **Model Simulation**  
   - The main script **nodModel_Run.m** calls the ODE solver (*ode15s*) to simulate system dynamics

6. **Output Calculation**  
   - Nitrogen fixation rate and efficiency are computed from simulation results
