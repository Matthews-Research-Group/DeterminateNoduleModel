## Data Description

This folder contains all datasets required to reproduce the results presented in the associated study.

### Dataset Overview

1. **Edata**  
   List of enzyme names used in the model.

2. **LSA_ALTNout_50% & LSA_gcgn_50%**  
   Results of local sensitivity analysis (LSA) for nitrogen fixation rate and efficiency, with parameter perturbations of ±50%.

3. **Nfix_pairwise & gcgn_pairwise**  
   Pairwise analysis results for nitrogen fixation rate and efficiency, based on 3-fold changes in expression of pathway enzyme pairs relative to their median flux map expression levels.

4. **Vmax_range**  
   Ranges of Vmax values for enzymes in glycolysis and the TCA cycle, used for constrained parameter sampling.

5. **alldata**  
   Aggregated results from simulations that successfully reached steady state.

6. **changeFBAratio_result**  
   Data used to reproduce Figure S16.

7. **eff_ineff_nodule**  
   Flux distributions for efficient and inefficient nodules, used for generating flux maps.

8. **fitness_comparison**  
    Data used to reproduce Figure S8.

9. **result_Vmaxdown** and **result_Vmaxup**  
    Data used to reproduce Figure S17 and Figure S18.

10. **wo_proteomicdata_result**  
    Data used to reproduce Figure S5.

---

### Notes
- All datasets are formatted to support direct reproduction of figures and analyses presented in the manuscript.  
- Refer to the main manuscript and supplementary materials for detailed descriptions of each analysis.
